Empire Hospitality Group - Single Page Optimized Build

This version keeps the full website on ONE index.html page.
No Story/Brands/Verticals/Presence/Contact page splitting is used.

Structure:
- index.html                  All visible website sections
- css/styles.css              Original styling (unchanged)
- js/core.js                  Scroll engine, preloader, navigation, menu
- js/scroll-animations.js     Original GSAP section animations
- js/hero-canvas.js           Original animated hero background canvas
- js/interactions.js          Original heading/button/card interactions
- assets/images/              Optimized WebP brand/logo assets

The JavaScript was split at the original comment boundaries without changing
animation values/easing/timing. UPS content remains removed.
